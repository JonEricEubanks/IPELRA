Technical Configuration

MGP tasks to configure before and during the conference.

  • Set production API URL
    Update VITE_API_BASE_URL in Azure Static Web App settings and rebuild the React app so the front end points to the deployed Function App.
    Owner: MGP
  • Add Static Web App URL to Function App CORS
    The Bicep template only allows localhost origins. Add the production SWA URL to the Function App CORS allow-list.
    Owner: MGP
  • Validate magic-link redirect URL
    Confirm APP_URL resolves to the Static Web App, otherwise magic links in emails will point to the wrong place.
    Owner: MGP
  • Apply final completion threshold
    Set COMPLETION_THRESHOLD_POINTS in the Function App configuration to the value calculated from the final sponsor mix.
    Owner: MGP Due: Before Oct 3
  • Enter and activate all sponsors
    Use the admin portal at /admin/sponsors to add or import every sponsor, test each answer keyword with the fuzzy tester, and set each one isActive = true.
    Owner: MGP Due: Before Oct 3
  • Keep passport closed until opening
    Leave PASSPORT_LIVE=false during setup. Flip it to true on the morning of October 5 via Azure CLI or portal.
    Owner: MGP Due: Morning of Oct 5
  • Verify passport lock time
    Confirm PASSPORT_LOCK_UTC=2026-10-11T00:00:00Z so the passport auto-locks at 7:00 PM Central on October 10.
    Owner: MGP

Pre-Conference Testing

Complete at least 48 hours before October 5.

  • Attendee magic-link end-to-end test
    Request a link from /login with a personal email, confirm delivery within 2 minutes, click it, and land on the onboarding page.
  • Spam and deliverability check
    Ensure the magic-link email lands in the inbox, not spam/junk. If it hits spam, revisit SPF/DKIM/DMARC and sender reputation.
  • Admin login test for every admin email
    Each configured admin should log in to /admin successfully and reach the dashboard.
  • Sponsor check-in test
    Test correct and intentionally incorrect answers for each sponsor to verify the fuzzy matcher and hint behavior.
  • Device testing
    Open the app on a real iPhone (Safari) and Android Chrome to confirm no zoom bugs, bottom nav is visible, and check-in works.
  • Completion email and leaderboard
    Trigger a completion and confirm the congratulations email is received and the leaderboard updates.
  • Emergency export and readiness check
    Test /api/admin/export with the x-export-secret header and review the /admin/readiness dashboard pre-flight.
  • Monitoring setup
    Open Application Insights live metrics and verify the admin dashboard auto-refreshes every 30 seconds.

Day-Of Runbook

October 5 through October 10.

  • Open passport on October 5 morning
    Set PASSPORT_LIVE=true and announce the URL/QR code to attendees.
  • Pre-warm the app
    Have a staff member open the app 10–15 minutes before doors open to avoid cold-start delays.
  • Keep admin dashboard visible
    Leave /admin/dashboard open during conference hours to monitor live metrics.
  • Export raffle CSV at end of conference
    Go to /admin/export, download the CSV, and save a backup to the IPELRA shared drive.
  • Confirm passport auto-locks
    No action needed if PASSPORT_LOCK_UTC is set, but verify the app shows the closed message after 7:00 PM CT on October 10.
